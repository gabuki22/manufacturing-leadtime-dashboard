# 고객 서비스 만족도 개선 리포트

> 데이터기반의사결정 7기 · 이기쁨 · 2026-07 · 데이터 전부 가공(합성)
> Day4 교안 형식 — BLUF·피라미드 원칙 + 신뢰 리포트 8구성요소

---

## 1. Executive Summary (결론 우선 · BLUF)
통신사 고객 500명 분석 결과, **전체 이탈율 11.8%**를 기준으로 이탈은 **세 지점에 집중**된다:
1. **불만을 표출한 고객** — 부정 VOC 고객 이탈율 **25.9%(2.2배)**
2. **저가·저사용 고객** — 베이직 20.1% vs 프리미엄 5.3%(4배), 이탈 고객 데이터 사용량 11.6GB(유지 26.5GB의 절반 미만)
3. **반복 재문의 고객** — 재문의 2회 이상 이탈율 **19.6%로 급등**

→ 리텐션 자원은 **부정 VOC·2회+ 재문의·저가/저사용** 세그먼트에 우선 배치해야 한다.

## 2. 배경 · 목적
이탈률이 개선되지 않는 상황에서 "고객은 왜 이탈하는가"를 데이터로 규명하고, 감(感)이 아닌 근거로 리텐션 우선순위를 정하기 위함이다. 3주간 축적한 고객·상담·이용 데이터를 통합 분석했다.

## 3. 분석 방법론
- **데이터**: customers(500) · voc(1,307) · consultations(1,320) · satisfaction · usage_history · agents(20) — BigQuery `study` 데이터셋
- **기법**: 세그먼트 이탈율 비교, 상관계수 + p-value(유의성), 교란변수 층화, 체인(퍼널) 분석, VOC 주제·감성 분석
- **신뢰 원칙**: 표본 30건 미만은 참고용, 상관 ≠ 인과, 값은 원본에서 재계산

## 4. 주요 발견 (근거)
| 발견 | 수치 | 근거 강도 |
|------|------|-----------|
| 부정 VOC → 이탈 | 25.9% (전체 2.2배·81명) | 확인됨 |
| 요금제별 이탈 | 베이직 20.1% / 프리미엄 5.3% | 확인됨 |
| 반복 재문의 → 이탈 | 2회+ 19.6% (0회 6.8%) | 확인됨 |
| 이용량 격차 | 이탈 11.6GB / 유지 26.5GB | 확인됨 |
| VOC 부정 비중 | 해지관련 56% · 앱기능 52% · 품질 51% | 확인됨 |
| 상담원 번아웃 | eNPS −45, 초과근무↔CSAT r=−0.83 (p<0.05) | 확인됨 |

## 5. 해석
저가·저사용·불만 고객이 이탈의 핵심이다. 상담원 번아웃(초과근무↑)이 CSAT 저하로 이어지고, 낮은 CSAT가 재문의를 부르며, 반복 재문의가 이탈로 연결되는 **연쇄 구조**가 관찰된다. 다만 이는 상관관계이며 인과는 확정하지 않는다.

## 6. 개선 권고 (처방)
1. **부정 VOC·2회+ 재문의 고객 즉시 리텐션 케어** — 이탈 선행 신호를 조준
2. **베이직·저사용 고객 대상 업셀/혜택 설계** — 이탈율 최상위 세그먼트
3. **이메일 채널 응대 품질 개선** — CSAT 최저(2.55)·재문의 최다(34.4%) 채널
4. **상담원 번아웃 관리** — 초과근무 상한, CSAT 저하의 상류 원인
